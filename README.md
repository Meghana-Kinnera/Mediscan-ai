# 🩺 Mediscan AI

An intelligent AI-powered medical report analyzer that reads patient reports and provides quick, structured diagnostic summaries using Groq's high-speed LLMs.

---

## ✨ Features
- 📄 **Multi-Format Support:** Reads medical reports in text and document formats.
- ⚡ **Groq Powered:** Ultra-fast diagnosis generation using Groq LLM API.
- 🌐 **Web Interface:** Clean and responsive UI built with Flask and HTML/CSS.
- 📊 **Structured Insights:** Highlights key metrics, diagnosis, and action items.

---

## 🛠️ Tech Stack
- **Backend:** Python, Flask
- **AI/LLM:** Groq API / AI Agents
- **Frontend:** HTML5, CSS3, Templates
